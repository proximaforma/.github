# Proxima Forma

**A shared editable canvas for people and AI agents.**

Create, refine, inspect and export designs together. Build landing-page concepts, UI mockups and vector artwork, keep designs editable, and work with connected agents on the same canvas.

[Open Proxima Forma](https://proximaforma.com) · [Documentation](https://proximaforma.com/docs/mcp) · [Support](https://proximaforma.com/support)

## Proxima Forma for Claude

The [Claude plugin](https://github.com/proximaforma/claude-plugin) combines a design workflow skill with our hosted MCP connector. Use Claude to read existing artboards, create and edit designs, inspect changes, discuss feedback and export SVGs.

- **MCP endpoint:** https://proximaforma.com/mcp
- **Authentication:** OAuth with automatic client registration.
- **Access:** approve read, comment or design permissions for your canvas.
- **Package:** MIT-licensed configuration, workflow skill and documentation, with brand rights reserved.

In Claude Code:

```text
/plugin install proxima-forma --marketplace proximaforma/claude-plugin
```

See the plugin repository for setup instructions and current directory-submission status.
